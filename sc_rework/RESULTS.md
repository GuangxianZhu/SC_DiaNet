# SC 跑分块 DiaNet：第一轮结果（2026-10-05）

所有模型都用 MNIST 训练集的前 55k 张训练，用后 5k 张验证集选模型。SC 精度在前 1000 张测试图上测得。

| 模型 | 非零权重 | 浮点测试精度 | SC @64 | SC @256 | SC @1024 |
|---|---|---|---|---|---|
| 分块 DiaNet，普通训练 | 10.3k | 94.96% | 11.7% | 12.5% | 22.1% |
| 同上 + 时间置换去相关 | | | 11.7% | 22.8% | 40.1% |
| 分块 DiaNet，SC 感知训练（噪声 L=256） | 10.3k | 94.90% | 11.1% | 35.4% | 67.9% |
| **同上 + 时间置换去相关** | | | **33.5%** | **74.3%** | **89.0%** |
| 全连接 784-100-200-10，普通训练 | 100.4k | 97.78% | 19.2% | 45.9% | 81.5% |
| 同上 + 去相关 | | | 23.0% | 53.2% | 83.3% |
| 同参数量 MLP 784-13-10，普通训练 | 10.3k | 92.20% | 37.3% | 64.2% | 82.6% |

SC 模型配置：双极性编码、XNOR 乘法、APC 累加、Btanh（饱和计数器，r = 2·r_scale·m，r_scale 在验证集上选）。随机数用理想随机源，没有模拟 LFSR。

## 结论
- 不加处理直接把 DiaNet 搬到 SC 上会崩溃。主网络有 24 层，比特流误差逐层累积；FSM 输出的时间相关性又让 Btanh 的增益不够，激活值放不大。
- SC 感知训练（在每个 tanh 后注入 L 位比特流的采样噪声）加上去相关，能把 L=1024 时的精度拉回 89%。
- 用浮点加噪声来模拟时（`dia_noise256` 模型）：L=1024 时 92.6%，L=256 时 89.7%。说明剩下的差距主要来自 FSM 的相关性，而不是采样噪声。
- **公平性提醒**：全连接和 MLP 基线还没有做 SC 感知训练。原仓库 `inf_1_clp0.5.ipynb` 里的全连接网络在 L=1024 时报告了 97.2%（权重截断到 0.5 加剪枝，激活接近饱和）。要声称 DiaNet 胜出，必须先让基线也用上同样的技巧。

## 硬件估算（Yosys 0.69，`synth -noabc`，按门数折算成等效门 GE）
- SC 神经元（XNOR + APC + Btanh）：扇入 3 约 110 GE，扇入 8 约 184 GE，扇入 100 约 1388 GE，扇入 784 约 9684 GE。
- 整个网络的神经元逻辑：DiaNet 共 2241 个神经元，约 0.32M GE；全连接共 310 个神经元，约 1.27M GE。以上不含 SNG、权重存储和去相关电路。
